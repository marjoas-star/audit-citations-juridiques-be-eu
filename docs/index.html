Audit des citations juridiques · Belgique, UE, CEDH

Installer le skill dans Claude, en cinq étapes

Ce skill fait vérifier par Claude les références et les citations d'un document juridique dans les sources officielles. L'installation prend dix minutes et ne se fait qu'une fois. Aucune connaissance informatique n'est nécessaire.

Avant de commencer

Un abonnement Claude payantPro, Max, Team ou Enterprise, qui donne accès à Cowork.
L'application de bureau ClaudeSur Mac ou Windows. Elle fournit le navigateur dont le skill a besoin.
Dans un cabinet ou une institutionVotre administrateur Claude doit avoir activé les réglages de l'encadré en bas de page.

  1. Télécharger le fichier du skill

    Télécharger le skillaudit-citations-juridiques-be-eu.zip · toujours la dernière version

    Un clic suffit : le fichier arrive dans vos Téléchargements. Aucun compte GitHub n'est nécessaire.

    Ne décompressez pas ce fichier. Claude attend l'archive .zip telle quelle.

    Sur Mac avec Safari, le fichier est décompressé automatiquement et vous obtenez un dossier. Deux solutions : clic droit sur le dossier › Compresser « audit-citations-juridiques-be-eu », ce qui recrée un fichier .zip utilisable ; ou, une fois pour toutes, Safari › Réglages › Général et décochez « Ouvrir les fichiers fiables après téléchargement ». Chrome et Firefox ne décompressent pas.

  2. Autoriser les skills

    Dans l'application Claude, ouvrez Paramètres › Capacités et activez l'exécution de code et la création de fichiers.

    Sans cette option, aucun skill ne fonctionne.

  3. Importer le skill

    • Toujours dans les paramètres, rubrique Personnaliser, ouvrez Compétences.
    • Cliquez sur le bouton + Ajouter, en haut à droite, puis sur Importer une compétence.
    • Choisissez le fichier .zip téléchargé à l'étape 1.
    • Vérifiez que audit-citations-juridiques-be-eu apparaît dans vos compétences et que son interrupteur est bleu. La mention « Ajoute uniquement des instructions pour Claude » est normale, de même que « v1 » : c'est le compteur de l'application, pas la version du skill.

  4. Choisir le navigateur intégré

    Ouvrez Paramètres › Cowork et choisissez le navigateur intégré comme navigateur préféré.

    Pourquoi : EUR-Lex, CURIA, HUDOC et le Conseil d'État refusent les connexions qui viennent de serveurs. Le navigateur intégré fonctionne depuis votre ordinateur, et ces sites l'acceptent. Sans lui, ces sources ne seront vérifiées que partiellement.

  5. Lancer un premier audit

    • Démarrez une nouvelle tâche Cowork dans l'application de bureau.
    • Joignez votre document (PDF ou Word) avec le trombone.
    • Copiez cette demande :
    Utilise le skill audit-citations-juridiques-be-eu pour vérifier toutes les références et citations du document joint. Produis un rapport en français, en PDF. Le document se place à la date du 1er mars 2024.

    Remplacez la date par celle de votre document. Pour un rapport en néerlandais, en allemand ou en anglais, remplacez aussi « en français ».

    Claude vérifie d'abord ses accès, compte les sources et annonce une durée : environ une minute par source, souvent moins. Une douzaine de références prend 5 à 15 minutes. Laissez l'application ouverte pendant ce temps.

    Il indique aussi la date juridique à laquelle il vérifiera les textes : celle que vous avez donnée ou, à défaut, celle qu'il déduit du document. Si elle ne vous convient pas, répondez simplement, par exemple « vérifie au 1er janvier 2016 ».

Pour l'administrateur (Team, Enterprise)

À transmettre à la personne qui gère votre compte Claude :

  • Organization settings › Cowork : activer Cowork et le navigateur intégré.
  • Organization settings › Capabilities : activer les Skills, « Code execution and file creation » et la recherche web.
  • Si l'accès réseau de l'exécution de code est restreint, autoriser les domaines listés dans le mode d'emploi (EUR-Lex, CURIA, HUDOC, Moniteur belge, Conseil d'État, Cour constitutionnelle…).

Si quelque chose coince

Claude répond sans utiliser le skill

Citez son nom dans la demande, comme dans le texte à copier, et vérifiez à l'étape 3 que son interrupteur est activé.

L'import refuse mon fichier

Vous avez sans doute importé un dossier décompressé. Reprenez l'étape 1 avec le bouton de téléchargement, ou recompressez le dossier comme indiqué pour Safari.

Presque tout est « non vérifiable »

La recherche web ou le navigateur intégré manque, ou l'application a été fermée pendant l'audit. Vérifiez l'étape 4 et relancez dans une nouvelle tâche. « Non vérifiable » ne veut pas dire « erroné ».

Installer une nouvelle version

Téléchargez la nouvelle archive avec le bouton de l'étape 1 (il donne toujours la dernière version). Dans Paramètres › Compétences, ouvrez la fiche du skill, menu ⋮ › Supprimer, puis refaites l'étape 3. N'utilisez pas « Remplacer » : la fiche se dit mise à jour mais garde l'ancien contenu. Pour vérifier la version installée : onglet Contenu de la fiche, fichier SKILL.md, sous le titre (la mention « v1 » de la fiche est un compteur propre à l'application).

Vous utilisez ChatGPT plutôt que Claude ?

Le même fichier .zip s'importe dans ChatGPT (offres Business, Enterprise, Healthcare et Edu) : barre latérale › Plugins › onglet Skills › Create › Upload from your computer. Lancez ensuite l'audit dans ChatGPT Work, de préférence dans l'application de bureau. Ce parcours n'a pas encore été testé : voir le mode d'emploi.

Voir toutes les versions et leurs notes

Page Releases du dépôt, rubrique « Assets » de chaque version. Le fichier qui se termine par « -complet » est réservé à la maintenance.

Votre avis

Une erreur que le rapport n'a pas vue, une fausse alerte, une conclusion peu claire, ou tout simplement un audit utile ? Dites-le en deux minutes, sans créer de compte : formulaire de retour (aussi en néerlandais, allemand et anglais). Le lien figure aussi à la fin de chaque rapport. Ne collez jamais de document confidentiel : la référence en cause et la source officielle suffisent.

Vous avez un compte GitHub ? Une étoile sur la page du projet aide d'autres juristes à le découvrir.

Mode d'emploi complet (accès, lecture du rapport, confidentialité) : français · Nederlands · Deutsch · English

Les libellés des menus sont ceux de l'interface française de Claude ; ils peuvent évoluer. Version 0.9, en essai public avant la 1.0 : relisez toujours les corrections proposées avant de les reporter.

Gratuit pour tous les juristes, y compris dans leur pratique professionnelle (auditer ses documents, ceux de ses clients ou ceux de ses adversaires). Le skill ne peut être ni vendu ni intégré dans un produit payant : voir la licence.
