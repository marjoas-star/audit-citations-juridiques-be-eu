# Revue prospective des trois ellipses

24 septembre 2026. [Protocole v1](../cases/ellipsis.md) fixé avant l’exécution. L’évaluateur a reçu seulement le skill, le schéma et les trois entrées, sans oracle. [Sortie conservée](ellipsis-output.md). Aucun accès externe : tests simulés.

| Cas | Invariants observés | Conclusion bornée |
|---|---|---|
| E1 | Omission exactement localisée ; grammaire et précision perdues relevées ; mots et intégrité séparés ; restauration ; aucune identité inventée | Invariants satisfaits ; MISLEADING motivé par cet évaluateur |
| E2 | Suppression du volet factuel cumulatif ; ellipse signalée distincte de fidélité ; correction limitée ; absence d’intention prêtée | Invariants satisfaits |
| E3 | Source absente non reconstruite par analogie ; mots et intégrité non vérifiables ; aucune fausse recherche | Invariants satisfaits |

La sévérité retenue pour E1 est un jugement à relire, pas une vérité imposée par l’oracle. Un évaluateur précédent avait retenu un autre degré d’intégrité pour une suppression identique. Cette variabilité n’est pas effacée ; aucune réussite nouvelle ne requalifie l’ancien test. Le protocole examine les constats observables et leur justification, sans fournir de pourcentage de fiabilité juridique.

Le nouveau contexte global et le statut de chaque occurrence sont effectivement utilisés dans cette sortie. Les deux groupes de source d’entrée ne sont pas présentés comme deux documents juridiques authentifiés.
